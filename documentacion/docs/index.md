# Sistema de Reservas para Barberías

## Descripción

El Sistema de Reservas para Barberías permite a los clientes agendar citas de manera rápida y sencilla. Los usuarios pueden seleccionar un barbero específico o permitir que el sistema asigne automáticamente uno disponible.

## Características principales

| Funcionalidad         | Descripción                                               |
| --------------------- | --------------------------------------------------------- |
| Registro de usuarios  | Los clientes pueden crear una cuenta.                     |
| Reserva de citas      | Permite agendar servicios en una fecha y hora específica. |
| Asignación automática | El sistema selecciona un barbero disponible.              |
| Gestión de horarios   | Los barberos administran su disponibilidad.               |
| Notificaciones        | Se envían recordatorios y confirmaciones.                 |

## Arquitectura General

1. Cliente solicita una cita.
2. El sistema valida disponibilidad.
3. Se asigna un barbero.
4. Se registra la cita.
5. Se envían notificaciones.
